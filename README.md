# Seventeen Syllables of Debugging — Entry

One haiku about debugging, three lines in the 5-7-5 syllable shape,
at most 200 characters — a concrete picture, and a last line that
turns what came before.

## How it works

`main.py` writes the haiku to `/output/entry.txt`.
Stdlib only, offline, deterministic.

## The haiku

> three a.m. cursor
> blinks at the code I swore worked
> it never once did

5-7-5 syllables, 69 characters.
